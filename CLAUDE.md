# Claude Contract

Este projeto usa o mesmo contrato de trabalho descrito em `AGENTS.md`.

## Regras principais

- Menor mudança segura.
- Reusar código e padrões existentes.
- Validar com comandos executáveis.
- Usar Graphify para decisões arquiteturais quando `graphify-out/` existir.
- Confirmar no código qualquer relação inferida pelo Graphify.
- Manter documentação em pt-BR quando atualizar README, Wiki ou Swagger.

## Referências

- `AGENTS.md`: contrato operacional curto.
- `docs/prompt-playbook.md`: modelos de prompts e specs por tipo de tarefa.
- `graphify-out/GRAPH_REPORT.md`: relatório local de arquitetura.
